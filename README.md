# Concurrent Navigation Processes

This repository contains the code needed to run an agent-based model of concurrent human navigation processes. This is part of an on-going project in a collaboration between University of Augsburg, Germany and University of Örebro, Sweden. The description of the model and its newest state are described in the following papers: 

2026: "From sequential decisions to concurrent processes: advancing human navigation models for simulation" published in presented by Sabine Timpf and Franziska Klügl at the COSIT 2026 conference https://www.cosit2026.uk/

2025: "Realistic Agent Behaviour based on Concurrent Process Architectures – Modelling Human Navigation" published and presented by Sabine Timpf and Franziska Klügl at the EUMAS 2025 conference https://euramas.github.io/eumas2025/.

## Running the model
If you want to run the code, you will have to install Java 1.8 on your machine, download the repository, start SeSAm.jar and then load the model file called campus_objectGraph_vXX.xml, where XX is a number. The newest version at the time of the COSIT short paper submission (May 2026) is number 125. The version at the time of the EUMAS conference (September 2025) is number 115. The version at the time for the EUMAS paper submission was number 94.
